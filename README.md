# A股主板右侧上升区间筛选器

这是一个基于 **Streamlit + AkShare** 的小工具，用于筛选 A 股主板中处于“右侧上升区间”的股票，并提供可随时刷新的界面。

## 筛选逻辑（默认）

- 主板代码范围：`600/601/603/605/000/001` 开头
- 趋势条件：`收盘价 > MA20 > MA60`
- 斜率条件：`MA60` 相比 10 天前上行
- 区间位置：当前价格位于近 120 日振幅区间的 `52% ~ 98%`

> 你可在页面中调整参数。

## 使用方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

打开浏览器访问：`http://localhost:8501`

## 刷新方式

- 点击页面按钮：**立即刷新**（会清理缓存并重新拉行情）
- 勾选：**每60秒自动刷新**

## 说明

- 数据来源：AkShare（东方财富接口）
